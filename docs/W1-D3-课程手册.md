## 上午：grep 全家桶（约 3h）

### 知识地图：grep 家族三兄弟

| 命令 | 正则引擎 | 速度 | 什么时候用 |
|---|---|---|---|
| `grep` | 基础正则 BRE | 最快 | 简单匹配（固定字符串、基本通配） |
| `egrep` = `grep -E` | 扩展正则 ERE | 快 | **日常主力**：`|` `()` `+` `?` 直接用 |
| `fgrep` = `grep -F` | 无正则（纯字符串） | 最快 | 搜的字符串里含特殊字符（如 `$` `.`），不想被正则解释 |

> 记忆钩子：E=Extended（扩展）、F=Fixed（固定字符串）。新脚本里推荐写 `grep -E` 而不是 `egrep`（规范）。

**高频六选项**（面试必问，逐条敲 + 把输出记进笔记）：

```bash
# ① -v 反向匹配：显示【不包含】模式的行——你摸底的空白，今天补上
grep -v '^#' /etc/ssh/sshd_config | head -5     # 只看配置文件的有效行（不含注释）

# ② -n 显示行号
grep -n "502" access.log

# ③ -c 只数数量（count），不显示内容
grep -c "200" access.log

# ④ -i 忽略大小写
grep -i "GET" access.log        # 同时匹配 GET / get / Get

# ⑤ -r 递归搜索目录（在代码/配置目录里找字符串，天天用）
grep -rn "PermitRootLogin" /etc/ssh/

# ⑥ -o 只输出匹配到的部分（不是整行）——统计场景神器
grep -o "192.168.100.10" access.log | wc -l
```

**组合拳初体验**（预习 W3 的管道流）：

```bash
# 统计每个 IP 出现次数（面试笔试高频题：Top IP）
grep -oE "^[0-9.]+" access.log | sort | uniq -c | sort -rn | head -3

# 只看错误行（401/403/502）
grep -E " (401|403|502) " access.log
```

### 实验 1：把昨天的知识串起来——"配置文件有效行查看器"

```bash
# 需求：看 sshd 配置，只要生效行（去注释、去空行）
grep -vE '^\s*(#|$)' /etc/ssh/sshd_config

# 拆解（务必自己拆一遍，这是今天的核心理解点）：
# ^\s*   行首的任意空白
# (      分组开始
# #      注释符
# $      或行尾（即空行）—— 注意 | 的"或"需要 -E
# )      分组结束
```

这一条命令吃透了，`grep -v '^#'` 的升级版你就都会写了。**面试官问"怎么只看配置文件生效项"，这就是满分答案。**

## 下午：正则表达式入门（约 3h，重头戏）

> 学正则的心法：**正则是"描述字符模式"的迷你语言**，不是背符号，是学"怎么把一句话需求翻译成模式"。今天只学 BRE/ERE 通用核心，学完三剑客全部受益。

### 核心符号表（先通读 10 分钟，再逐个实验）

| 符号 | 含义 | 记忆钩子 |
|---|---|---|
| `.` | 任意**单个**字符 | 一个占位 |
| `*` | 前面的东西出现 **0 次或多次** | 零到无穷 |
| `+` | 前面的出现 **1 次或多次**（ERE） | 至少一次 |
| `?` | 前面的出现 **0 次或 1 次**（ERE） | 可有可无 |
| `^` | 行首锚点 | 鱼钩钩住开头 |
| `$` | 行尾锚点 | 钩住结尾 |
| `[abc]` | 字符集合，匹配 a 或 b 或 c | 菜单点菜 |
| `[a-z]` `[0-9]` | 范围集合 | 区间 |
| `[^abc]` | **否定集合**：不是 a/b/c 的字符 | ^ 在集合内=排除 |
| `\b` | 单词边界 | 词的围墙 |
| `{n,m}` | 前面的出现 n 到 m 次（ERE） | 精确配额 |
| `()` | 分组（ERE） | 打包 |
| `|` | 或（ERE） | 单选题 |

**两个最容易混的（面试挖坑点）**：
1. `^` 在**模式开头** = 行首锚点；`^` 在**集合内第一位** `[^x]` = 排除。同一个符号两种身份，看位置。
2. `*` 是"前面的内容"重复——`a*` 匹配 `""`、`a`、`aa`…**不是匹配任意字符串**！任意字符串是 `.*`。

### 实验 2：逐符号验证（用 /etc/passwd 和 access.log 当靶场）

```bash
# 锚点练习：以 root 开头的行
grep "^root" /etc/passwd
# 以 nologin 结尾的行
grep "nologin$" /etc/passwd | head -3
# 同时锚住两头：整行就是 root 四个字符（^ 与 $ 夹住）
grep "^root$" /etc/passwd

# 集合练习：用户名以 a-c 开头的行
grep -E "^[a-c]" /etc/passwd
# 否定集合：第二段（密码位）不是 x 的
grep -E "^[^:]+:[^x]" /etc/passwd

# 量词练习：连续 3 个数字（如 UID）
grep -oE "[0-9]{3}" /etc/passwd | head -5
# IP 段：1-3 位数字 + 点（粗匹配，不是严格 IP 校验）
grep -oE "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}" access.log | sort -u

# 或与分组：GET 或 POST 开头的请求
grep -E '"(GET|POST)' access.log
# 取反组合：既不是 200 也不是 401 的状态码行
grep -vE ' (200|401) ' access.log
```

### 实验 3：真实需求驱动（正则只在需求里才学得会）

**需求 A**：从 access.log 里找出所有 5xx 服务器错误：

```bash
grep -E ' 5[0-9]{2} ' access.log
# 拆解：空格 + 5 开头 + 任意两位数字 + 空格。为什么两侧加空格？防止匹配到字节数或其他数字
```

**需求 B**：找出日志里所有图片请求（.png/.jpg/.gif 结尾）：

```bash
grep -E '\.(png|jpg|gif) ' access.log
# 注意 \. ：点号要匹配"字面的点"必须转义，否则匹配任意字符
```

**需求 C（进阶）**：伪造一批日志练手，统计 502 的次数和占比：

```bash
for i in $(seq 1 50); do
  ip="192.168.100.$((RANDOM % 5 + 10))"
  code=$((RANDOM % 10 < 7 ? 200 : (RANDOM % 5 + 500)))
  echo "$ip - - [21/Oct/2026] \"GET /api/x$i HTTP/1.1\" $code 1024" >> test.log
done
total=$(wc -l < test.log)
err=$(grep -cE ' 5[0-9]{2} ' test.log)
echo "5xx 占比: $((err * 100 / total))%"
```
