- [ ] ⚠️ 软硬链接与 inode（硬链接跨文件系统/目录限制、引用计数机制）

- [ ] ⚠️ `$@` 与 `$*` 加引号后的差异

### 命令/工具熟练度
- [ ] find 条件+动作全组合（-mtime/-size/!/-exec {} \; 与 + 与 xargs）

- [ ] ⚠️ Linux 静默失败意识：通配符不匹配、ln 不校验目标、history 展开
