## 一、下载 Rocky Linux 9.8（今天的第一件事）

**为什么是 9.8 而不是 10？** RHCE 考试（EX200/EX294）基于 **RHEL 9**，Rocky 9.8 与其二进制兼容；Rocky 10 是下一代（RHEL 10 底座），命令有差异，练错了反而添乱。9.8 官方维护到 2032 年，放心用。

### 下载链接（官方源，复制到浏览器或迅雷）

| 镜像 | 用途 | 选择建议 |
|---|---|---|
| [DVD ISO](https://download.rockylinux.org/pub/rocky/9/isos/x86_64/Rocky-9.8-x86_64-dvd.iso) | 全量安装盘（约 10GB） | **推荐**：装完自带常用软件包，虚拟机不用联网也能装 |
| [Minimal ISO](https://download.rockylinux.org/pub/rocky/9/isos/x86_64/Rocky-9.8-minimal-x86_64.iso) | 最小安装（约 2GB） | 带宽紧张时用，但装完要配网络源装很多东西 |

下载完校验完整性（养成习惯，运维基本功）——对照官方 [CHECKSUM 文件](https://download.rockylinux.org/pub/rocky/9/isos/x86_64/CHECKSUM)，在 Windows 上用：

```powershell
Get-FileHash .\Rocky-9.8-x86_64-dvd.iso -Algorithm SHA256
```

如果官方源慢，可用国内镜像站（把域名换成 `mirrors.ustc.edu.cn/rocky` 或 `mirrors.aliyun.com/rockylinux`，路径不变）。

## 二、创建第一台虚拟机（今天做完 1 台，明天复刻另外 2 台）

以 VMware Workstation 为例（VirtualBox 同理）：

1. 新建虚拟机 → 典型 → 稍后安装操作系统（**别选"简易安装"，会跳过分区界面**，而分区正是 W6 考点）
2. 客户机操作系统：Linux → 版本选 **Rocky Linux 9 64位**（没有就选 Red Hat Enterprise Linux 9 64位）
3. 配置：**2 核 CPU / 4G 内存 / 磁盘 60G**（选"将虚拟磁盘拆分成多个文件"）
   - 装完系统后，再在"设置 → 添加"里**加一块 20G 磁盘**（W6 做 LVM 实验用，现在加好省得回头加）
4. 挂载 DVD ISO → 开机 → 进入安装界面

### 安装界面关键设置（考试会考，跟着做）

| 项 | 设置 |
|---|---|
| 语言 | 中文或英文都行（**建议英文**，生产环境全英文，早适应） |
| Installation Destination | 选默认 60G 盘 → 选 **Custom 自定义分区**（重点练习！） |
| 分区方案 | 标准分区：`/boot` 1G、`swap` 2G、`/` 其余全部（先会标准分区，LVM 是 W6 的事） |
| Software Selection | **Minimal Install**（纯净环境，缺什么装什么，学习效果最好） |
| Root Password | 设一个记得住的，**勾选 Allow root SSH login with password**（实验机方便，生产环境禁） |
| 用户 | 创建普通用户 `ops`，勾选 Make this user administrator |
| Network | 安装时点进去把网卡 **ON**（默认是关的，不打开装完没网） |

5. 装完重启 → 登录 → **立刻拍快照**，命名 `rocky98-base-clean`

### 装完第一件事：换国内 yum 源（练手 dnf 命令）

```bash
# 先看当前源（记住这个命令，RHCE 常用）
dnf repolist

# 备份官方源，换成中科大镜像
sudo sed -e 's|^mirrorlist=|#mirrorlist=|' \
         -e 's|^#baseurl=http://dl.rockylinux.org/$contentdir|baseurl=https://mirrors.ustc.edu.cn/rocky|' \
         -i /etc/yum.repos.d/Rocky-*.repo

# 清缓存并重建
sudo dnf clean all && sudo dnf makecache

# 装几个今天就要用的工具（顺便体验 dnf）
sudo dnf install -y vim git tar wget
```

### 第二件事：三台互通的准备工作（今天先做通第一台）

```bash
# 查看本机 IP（新命令：RHEL 9 已移除 ifconfig）
ip addr
# 记下 ens160/ens33 的 IP，比如 192.168.xxx.128

# 确认能上网
ping -c 3 mirrors.ustc.edu.cn
```

> Windows 宿主机与虚拟机网络模式选 **NAT** 即可互通。三台机建议在 VMware 虚拟网络编辑器里固定子网段，DHCP 起始地址靠后，减少 IP 变动。

## 三、Git 学习仓库（已经帮你建好了本地骨架，跟着下面步骤接手）

老师已在你的电脑上建好 `C:\Users\Administrator\linux-ops-learning`，结构如下：

```
linux-ops-learning/
├── README.md          # 仓库门面：目录说明 + 20周进度勾选表
├── .gitignore         # 告诉 git 哪些文件不用管（iso/vmdk 等大文件）
├── notes/             # 每周笔记（w01、w02...）
│   └── w01-linux-advanced/
├── scripts/           # 实战脚本（W2 起开始填，简历素材）
├── labs/              # 实验记录（含踩坑，面试素材）
├── interview/         # 面试题口述答案
└── docs/              # SOP 排障套路文档
```

### 你要亲手做的三步

**第 1 步：验证本地仓库，做你的第一次提交**

打开 PowerShell 或 Git Bash，逐条敲（**不要复制粘贴，敲一遍肌肉记忆才是你的**）：

```bash
# 进入仓库
cd C:\Users\Administrator\linux-ops-learning

# 看看 git 现在的状态（红色=未跟踪的新文件）
git status

# 把所有新文件放入暂存区（. 表示当前目录全部）
git add .

# 再看一次：绿色了 = 已暂存
git status

# 提交到本地仓库，-m 后面是说明（格式：周次天+做了什么）
git commit -m "w01d01: 初始化学习仓库结构"

# 查看提交历史
git log --oneline
```

**第 2 步：注册 GitHub 并建远程仓库**

1. 打开 https://github.com/signup ，用邮箱注册（用户名建议专业一点，以后简历上要写，比如 `wangchen-ops`，不要 `qq123456`）
2. 登录后点右上角 **+** → **New repository**
3. Repository name 填 `linux-ops-learning`，选 **Public**（就是要给面试官看的），**不要**勾选 Add README（本地已有）
4. 点 Create repository，**先停在生成的页面别关**

**第 3 步：配置 SSH 密钥并推送**

```bash
# 1. 生成 SSH 密钥（把邮箱换成你 GitHub 注册邮箱；一路回车即可）
ssh-keygen -t ed25519 -C "你的GitHub邮箱"

# 2. 查看公钥内容并复制全部输出
cat ~/.ssh/id_ed25519.pub

# 3. 回到浏览器：GitHub → 头像 → Settings → SSH and GPG keys
#    → New SSH key → 把刚才复制的内容粘贴进去 → Add

# 4. 测试连通（第一次会问是否信任，输 yes）
ssh -T git@github.com
# 看到 "Hi xxx! You've successfully authenticated" 即成功

# 5. 关联远程仓库（把地址换成你自己的）
git remote add origin git@github.com:你的用户名/linux-ops-learning.git

# 6. 推送！第一次推送加 -u 建立跟踪关系，以后只需 git push
git push -u origin main
```

刷新 GitHub 页面，看到 README 出现——**你的学习档案正式上线**。
