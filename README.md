# linux-ops-learning · 云原生运维 20 周学习仓库

> 目标：从 Linux 使用者成长为云原生运维工程师（RHCE + K8s + 可写进简历的项目）
> 周期：20 周 · 8h × 6 天/周 · 起始日期 2026-10-20

## 目录说明

| 目录 | 用途 |
|---|---|
| `notes/` | 每周学习笔记（按 w01、w02... 编号） |
| `scripts/` | 实战脚本（监控/巡检/备份等，简历素材） |
| `labs/` | 实验记录（每做一个实验写一个 md，含踩坑） |
| `interview/` | 面试题口述答案整理 |
| `docs/` | SOP 文档（排障套路、部署手册） |

## 使用约定

1. 每天学习结束提交一次：`git add . && git commit -m "w01d01: 笔记+软硬链接实验"`
2. 每周日晚推送到 GitHub：`git push`
3. commit message 格式：`周次+天: 做了什么`
