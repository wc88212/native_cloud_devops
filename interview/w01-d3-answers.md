## Q1 `grep -v '^#' /etc/fstab` 的效果？^ 是什么身份？

**标准版**：`-v` 反向匹配 + `^#`（行首锚点 + #）= **显示所有不以 # 开头的行**，即去掉注释行。
**满分追加**：此命令的缺陷是**空行还在**；生产版 `grep -vE '^\s*(#|$)'` 一次性去掉注释和空行。

## Q2 grep / grep -E / grep -F 的区别？

| | 正则引擎 | 特性 | 场景 |
|---|---|---|---|
| `grep` | 基础正则 BRE | `\|` `\(\)` 才生效 | 简单匹配 |
| `grep -E` | 扩展正则 ERE | `|` `()` `+` `?` `{n,m}` 直接用 | **日常主力** |
| `grep -F` | 无正则 | **Fixed：纯字符串**，`$` `.` `*` 全部字面化 | 搜索内容本身含特殊字符时（如 `${PATH}`） |

**易混警告**：`grep -F` ≠ `awk -F`（后者才是分隔符）。记忆：E=Extended，F=Fixed。

## Q3 `a*` 和 `.*` 的区别？

- `a*`：字符 **a** 出现 0 次或多次 → 匹配 `""`、`a`、`aa`…
- `.*`：**任意字符**（每次可不同）重复任意次 = 任意字符串
- **本题真正的考点**：`a*` 匹配空串 → `grep "a*" 任何文件` 输出**全部行**（每行都含 0 个 a）。答出这条才是满分。

## Q4 递归找 /etc 下含 timeout 的文件并显示行号

```bash
grep -rni 'timeout' /etc/ssh
# -r 递归 / -n 行号 / -i 忽略大小写（生产配置大小写不定）
```

## Q5 统计日志中 5xx 占比（完整命令链）

```bash
total=$(wc -l < xxx.log)
err=$(awk '$9>=500 && $9<600' xxx.log | wc -l)
echo "5xx 占比: $((err * 100 / total))%"
```

**要点**：① 状态码必须锚定到第 9 列（awk 按列），不能裸匹配 `5[0-9]{2}`（会误伤时间、字节数里的三位数）；② 审题：题目要"占比"不是"行数"，分母分子都要有。

## 本日实战沉淀（面试可讲的案例）

1. **锚点丢失案**：`grep -oE "[0-9.]+"`（丢了 `^`）把日期 21、年份 2026、版本 1.1 全抠出来各计 6 次——行内所有数字串都被匹配。教训：实验现象与预期不符，先原样重跑命令排除抄写偏差。
2. **结构化日志选型**：找文本用 grep，按列分析用 awk（`awk '$1'` 是条件不是取列，取列必须 `{print $1}`——亲测）。
3. **history 展开坑**：双引号内 `!:1001` 触发 bash history 展开（`!:` = 取历史命令参数），报 `bad word specifier`。含 `!$` 等特殊字符一律单引号。
4. **定位第 N 列套路**：`^[^:]+:` 重复 N-1 次跳过前 N-1 列；`^` 双身份判定：在 `[` 后第一位 = 否定集合，裸露 = 行首锚点。
