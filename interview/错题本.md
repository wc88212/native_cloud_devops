# 第一部分：面试题错题

## D2-1 软硬链接区别？（评级 ⭐⭐⭐⭐⭐，方向对，缺两细节）
- **我的原答案**：硬链接同 inode 第二名字，删源不受影响；软链接独立 inode 内容是路径，删源悬空。
- **遗漏点**：① 硬链接**不能跨文件系统、不能链接目录**；② 回收机制是 inode **引用计数**（2→1，归零才回收）
- **正确答案**：见 `interview/w01-d2-answers.md`

## D2-2 find -mtime +7 与 -7（评级 ⭐⭐⭐，太薄）
- **遗漏点**：三要素齐全才满分——`-mtime` 是内容修改时间、单位天；+7=7天前、-7=7天内；分钟级变体 `-mmin`
- [ ] 复习

## D2-3 find -exec 的 {} 和 \; 是什么（评级 ⭐，**未答**）
- **正确答案**：`{}` 是 find 结果的占位符（每找到一个文件填进去执行一次）；`\;` 是 -exec 命令的结束标记，`;` 是 shell 特殊字符不转义会被 shell 先吃掉
- [ ] 复习

## D2-4 磁盘满了如何定位（评级 ⭐⭐⭐，缺根因判断）
- **我的原答案**：df -h → du -sh
- **遗漏关键**：**du 与 df 对不上时** = deleted 文件被进程占用 → `lsof +L1`；清理用 `truncate -s 0` 而非 rm（rm 句柄占用不释放空间）
- **满分五步**：确认 → 定位 → 根因判断 → 处理（truncate/重载/扩容）→ 预防（logrotate/告警水位）
- [ ] 复习 ⚠️ 本题为面试高频大题，W6 做完实验后回来重写一遍

## D2-5 -exec {} \; / {} + / xargs 区别（评级 ⭐⭐⭐⭐，提问质量高）
- **我的结论**：默认用 `{} +`；多文件后台处理用 xargs
- **修正**：xargs 的正确适用场景是① `{}` 不在命令末尾（如 `cp {} /backup/`）② 需要并行 `-P4` ③ 结果要串复杂管道；非"后台"
- [ ] 复习

## D3-2 grep / grep -E / grep -F 区别（评级 ⭐⭐，**概念全错，重点复习**）
- **我的原答案**：-E 是"查找转义字符"、 -F 是"固定分隔符"——全错
- **正确答案**：E = Extended 扩展正则（|()+?{} 直接用）；F = Fixed 纯字符串（不做正则解释，搜 ${PATH} 这类含特殊字符的字面量）；**grep -F ≠ awk -F**
- [ ] 复习 ⚠️

## D3-3 a* 与 .* 区别（评级 ⭐⭐⭐⭐，表述有 bug）
- **我的原答案**：`.*` 是"任意**单个**字符出现 0 或多次"——"单个"用词错误
- **正确答案**：`.*` = 任意字符（每次可不同）重复任意次；**真考点**：`a*` 匹配空串 → `grep "a*"` 输出全部行
- [ ] 复习

## D3-5 统计 5xx 占比（评级 ⭐⭐，审题+精度双失分）
- **我的原答案**：`grep -E '5[0-9]{2}' xxx.log`
- **两处错**：① 未锚定到状态码列（误伤时间/字节数里的三位数）② 题目要"占比"，我只给了匹配
- **正确答案**：`awk '$9>=500 && $9<600'` + 分子分母计算百分比
- [ ] 复习

# 第二部分：实操/排障错题（RHCE 实操训练素材）

## D1-01 sed 批量改配置：通配符静默不匹配
- **现象**：`sed -i /etc/yum.repos.d/Rocky-*.repo` 报"没有那个文件或目录"
- **根因**：Rocky 9/10 的源文件名是**小写** `rocky-*.repo`；**通配符不匹配时 shell 原样传字符串，不报错**
- **正确**：`ls` 先确认文件名 → 再写命令；`-i.bak` 留备份
- [ ] 复习（重做：在 rocky1 上把 rocky.repo 改回 ustc 再改回来）

## D1-02 多行命令续行失败
- **现象**：从聊天窗口复制多行命令，shell 无输出/行为异常
- **根因**：`\` 续行符后混入不可见空格，续行断裂
- **正确**：长命令用单行版，或手敲续行
- [ ] 复习

## D1-03 dnf 锁等待
- **现象**：`正在等待 pid 为1144的进程退出`
- **根因**：前一个 dnf 卡死占锁；dnf 同时只允许一个实例
- **正确**：Ctrl+C 取消排队 → `ps -p 1144 -o pid,stat,etime,cmd` 看状态（D=不可中断睡眠，kill -9 都杀不动，只能等 IO 超时）→ 先 `kill`(15) 再 `kill -9`
- [ ] 复习 ⚠️（kill -15 vs -9 是面试高频）

## D1-04 版本陷阱：误装 Rocky 10
- **教训**：下载任何东西前**核对文件名**；官方下载页默认展示最新版
- **核实后结论**：RHCE 9 于 2026-09-30 退休，2026-10-01 起仅可考 RHEL 10 版本 → Rocky 10 正确
- [ ] 复习（记住：结论必须实时查证）

## D1-05 私网段误判
- **现象**：VM 拿到 172.10.0.x，出网异常
- **根因**：私网范围是 10/8、**172.16–172.31**、192.168/16 —— **172.10 不是私网**；VMware VMnet8 子网被设在公网段
- **正确**：虚拟网络编辑器改 VMnet8 子网为 192.168.100.0/24
- [ ] 复习 ⚠️（背私网段表，面试考点）

## D1-06 curl error 7 vs 404
- **error 7** = 网络层连不上；**404** = 路径/版本不存在（阿里云 rocky/10/ 路径实测 404）
- **正确方法论**：给的配置先实测再交付；`curl -o /dev/null -w '%{http_code}'` 探测
- [ ] 复习

## D2-07 ln -s 目标打错 → 悬空链接静默生效
- **现象**：`ln -sfn /opt/app/v1,0`（逗号）后 cat/cd 全报错
- **根因**：**ln -s 不校验目标是否存在**，创建"成功"
- **正确排查**：软链接出问题第一步 `ls -l` / `readlink` 看指向，而非反复 cat/cd
- [ ] 复习 ⚠️

## D2-08 xargs 遇文件名空格报错
- **解法**：`find -print0 | xargs -0`；`{} \;` 和 `{} +` 不受影响
- [ ] 复习

## D3-09 正则锚点丢失（见 D3-2 相关）
- [ ] 复习

## D3-10 history 展开：bad word specifier
- **现象**：`echo "test2:!:1001"` → `-bash: :1001: bad word specifier`
- **根因**：双引号内 `!:` 触发 history 展开
- **正确**：含特殊字符一律**单引号**
- [ ] 复习

## D3-11 awk '$1' 不是取列
- **根因**：awk 语法是 `模式 { 动作 }`；只有模式无动作 → 默认打印整行；取列必须 `{print $1}`
- [ ] 复习
